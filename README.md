# SAM'S FORGE · Terrain

Terrain sculptor for the Substrata pipeline (single-file HTML app).

## Deploy to Vercel (recommended)

1. Download `sams_forge.html` from the project artifacts.
2. Rename it to `index.html`.
3. In [Vercel](https://vercel.com): **Add New Project** → **Upload** the folder with `index.html`.
4. Framework preset: **Other**. Deploy.

Or from terminal in the folder that contains `index.html`:

```bash
npx vercel --prod
```

## Local

Open `index.html` in a browser (Three.js loads from CDN — needs network).
